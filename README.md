# Yixuan Zhu — Personal Portfolio

这是一个无需安装依赖的本地静态网站。

## 打开方式

直接双击 `index.html`，或在此目录运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 内容

- 默认跟随系统浅色 / 深色主题，也可手动切换并记忆本地偏好
- 十个项目组成同一条横向滚动轨道：前四个代表项目采用大幅展示，后六个以三组双层小卡片自然接轨
- 全部项目带年份、统一英文简介与独立视觉
- Research 四阶段切换会同步驱动数据整理、模型微调、旋律生成与理论评估四种可视化
- 研究课题、2023—2025 历程与 2025 年成果整合为一页
- 响应式桌面与移动端布局
- 尊重系统“减少动态效果”设置
